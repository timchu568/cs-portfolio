# RMA SQL Analysis

## Overview

This project used SQL to analyze return merchandise authorization (RMA) data for a fictional company. The analysis focused on identifying patterns in product returns and presenting the results in a way that could be useful to nontechnical stakeholders.

## Tools & Technologies

- MySQL
- SQL
- Relational databases
- Data analysis
- Table joins
- Aggregation
- Percentage calculations

## Analysis

The project analyzed:

- The number of returns by state
- The percentage of returns by product type
- Return patterns across related customer, order, and RMA data

SQL joins were used to connect the RMA, Orders, and Customers tables so that return activity could be analyzed using customer location and other available information.

## Key Findings

The analysis showed that return activity was concentrated in certain states, which could help identify locations for additional operational review.

The analysis also showed that product replacement or account refund processed accounted for 89.74% of all returns. This made it the most common return category in the dataset.

## Key Skills Demonstrated

- Writing SQL queries
- Joining multiple relational tables
- Grouping and aggregating data
- Calculating percentages
- Analyzing business data
- Identifying patterns in operational data
- Communicating findings to nontechnical stakeholders

## Project Context

This project was completed as part of coursework in database analysis and was designed to demonstrate how SQL can be used to turn operational data into information that can support business decisions.
