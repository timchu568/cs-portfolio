# Basketball Performance & Regression Analysis

## Overview

This project used Python and statistical analysis to examine the relationship between basketball team performance metrics and regular-season wins.

The analysis focused on average points scored, average Elo rating, and average Elo rating differential to determine how these variables were related to the number of regular-season wins.

## Tools & Technologies

- Python
- pandas
- Statistical analysis
- Pearson correlation
- Simple linear regression
- Multiple linear regression

## Analysis

The project included:

- Pearson correlation analysis to examine relationships between performance variables and regular-season wins
- Simple linear regression to evaluate individual predictors of wins
- Multiple linear regression to examine the combined relationship between multiple performance metrics and wins
- Interpretation of statistical results in a business-oriented context

## Key Skills Demonstrated

- Data analysis using Python
- Statistical reasoning
- Regression analysis
- Interpreting quantitative results
- Communicating analytical findings to a nontechnical audience

## Project Context

This project was completed as part of coursework in data analytics and statistics. The analysis was designed to demonstrate how statistical methods can be used to identify relationships within a dataset and communicate findings to stakeholders.
