# QuantigrationUpdates SQL Database

## Overview

This project used MySQL to create and analyze a relational database for a fictional company called Quantigration. The database was designed to organize customer, order, and return merchandise authorization (RMA) information.

The project focused on creating related tables, importing data, and using SQL queries to retrieve and analyze information from the database.

## Tools & Technologies

- MySQL
- SQL
- Relational databases
- Database design
- Data importing
- SQL joins
- Filtering and aggregation

## Database Structure

The database included three related tables:

- Customers
- Orders
- RMA

Primary and foreign keys were used to establish relationships between the tables. The Orders table was connected to Customers through CustomerID, and the RMA table was connected to Orders through OrderID.

## Analysis

The project included SQL queries to:

- Import customer, order, and RMA data
- Count orders for customers in specific locations
- Filter customers by state
- Join related tables to retrieve information across the database
- Group and count records based on specific criteria
- Update and delete records
- Export query results to a CSV file

## Key Skills Demonstrated

- Writing SQL queries
- Working with relational databases
- Using primary and foreign keys
- Joining multiple tables
- Filtering and grouping data
- Importing and exporting data
- Analyzing query results

## Project Context

This project was completed as part of coursework in database design and SQL. It demonstrates the use of SQL to organize relational data and retrieve information that can support business analysis and decision-making.
